# 🚀 Mini CRM

A modern Customer Relationship Management (CRM) system built with **Laravel 12**, **Livewire 3**, and **Tailwind CSS**.

> ⚠️ **Project Status:** This project is currently under active development. New features and improvements are being added continuously.

---

## 🛠️ Tech Stack

- Laravel 12
- Livewire 3
- Tailwind CSS
- MySQL
- Blade
- Alpine.js

---

## ✨ Features

### ✅ Implemented

- Authentication
- Dashboard
- Company Management
- Sales Opportunities
- Drag & Drop Sales Pipeline
- Responsive UI
- Clean & Modern Design

### 🚧 In Progress

- Customer Management
- Contacts
- Tasks & Activities
- Notes
- Calendar

- Reports

The goal of this project is to build a modern CRM system while following Laravel best practices, clean architecture, and a great user experience.

## 🚀 Installation

```bash
git clone https://github.com/your-username/mini-crm.git

cd mini-crm

composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate --seed

npm run dev

php artisan serve
```
